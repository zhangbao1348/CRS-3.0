# 订单报表功能分析

## 1. 页面内容

### 1.1 页面标题
- **报表**：页面顶部显示的标题

### 1.2 筛选区域
- **酒店**：下拉选择框，包含选项：

  - 上海宝丽嘉
  - 杭州钓美
- **预订日期**：日期范围选择器
- **快速选择**：下拉选择框，包含选项：

  - 本周
  - 上周
  - 本月
  - 上月
  - 今年
- **数据对比**：复选框，选择后显示订单日期选择器
- **订单日期**：日期范围选择器
- **快速选择**：下拉选择框，包含选项：
  - 同比
  - 环比
- **订单状态**：下拉选择框，包含选项：
  - 全部订单状态
  - 已确认
  - 已取消
  - 已入住
  - 已离店
- **市场代码**：下拉选择框，包含选项：
  - 请选择市场代码
  - 国内
  - 国际
  - 企业
- **渠道代码**：下拉选择框，包含选项：
  - 请选择渠道代码
  - 携程
  - 飞猪
  - Booking
- **房价大类**：下拉选择框，包含选项：
  - 请选择房价大类
  - 房费
  - 包价
  - 附加服务
- **分组依据1**：下拉选择框，包含选项：
  - 渠道
  - 酒店
  - 市场
- **分组依据2**：下拉选择框，包含选项：
  - 酒店
  - 房型
  - 价格计划
- **订单支付方式**：单选框组，包含选项：
  - 全部

- **可累积积分**：复选框

- **导出按钮**：点击导出报表

### 1.3 报表区域
- **表头标题**：显示当前周期和对比周期的日期范围
- **报表表格**：
  - 分组：显示渠道名称，合并相同渠道的行
  - 酒店：显示酒店名称
  - 当前周期数据（2022-07-01 - 2022-07-07）：
    - 订单数(单数)：显示订单数量和变化百分比
    - 订单总金额：显示订单总金额和变化百分比
    - 订单支付总积分数：显示积分数量和变化百分比
    - 间夜数：显示间夜数量和变化百分比
    - 间夜平均价：显示平均价格和变化百分比
  - 对比周期数据（2021-07-01 - 2021-07-07）：
    - 订单数：显示订单数量
    - 订单总金额：显示订单总金额
    - 订单支付总积分数：显示积分数量
    - 间夜数：显示间夜数量
    - 间夜平均价：显示平均价格
  - 操作：查看订单明细按钮

### 1.4 总计区域

- **总计表格**：

## 6. 总结

订单报表是CRS系统中用于分析酒店订单数据的功能模块。通过该页面，用户可以查看不同渠道、不同酒店的订单数据，并与历史数据进行对比，分析订单趋势和业绩表现。

页面设计清晰，功能完整，交互流畅。用户可以通过丰富的筛选条件来获取特定的订单数据，通过分组依据来组织报表数据，通过导出功能来保存报表数据。

报表数据展示详细，包括订单数、订单总金额、订单支付总积分数、间夜数和间夜平均价等关键指标，并与历史数据进行对比，显示变化百分比，帮助用户直观了解业务发展趋势。

未来可以通过后端API获取实时订单数据，实现更复杂的报表功能，如多维度数据分析、图表展示、自定义报表等。
