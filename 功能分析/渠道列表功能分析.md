# 渠道列表功能分析

## 1. 页面内容

### 1.1 页面标题
- **渠道管理**：页面顶部显示的标题，带有链接图标

### 1.2 标签页
- **已连接渠道**：显示已连接的渠道
- **可连接渠道**：显示可连接的渠道

### 1.3 渠道卡片
- **已连接渠道**：
  - 携程：带有携程Logo，背景为浅蓝色，显示"20产品在售"状态
  - 飞猪：带有飞猪Logo，背景为浅绿色，显示"20产品在售"状态
  - 红色加力：带有红色加力Logo，背景为浅红色，显示"20产品在售"状态
  - 美团：带有美团Logo，背景为浅黄色，显示"20产品在售"状态

- **可连接渠道**：
  - Booking.com：带有Booking.com图标，背景为浅灰色，显示"未连接"状态
  - Agoda：带有Agoda图标，背景为浅灰色，显示"未连接"状态
  - Expedia：带有Expedia图标，背景为浅灰色，显示"未连接"状态
  - Hotels.com：带有Hotels.com图标，背景为浅灰色，显示"未连接"状态

## 2. 交互逻辑

### 2.1 标签页切换
- **点击已连接渠道标签**：显示已连接的渠道列表
- **点击可连接渠道标签**：显示可连接的渠道列表

### 2.2 渠道卡片点击
- **点击飞猪卡片**：跳转到飞猪设置页面 (`/channel-management/fliggy-setting`)
- **点击携程卡片**：跳转到携程设置页面 (`/channel-management/ctrip-setting`)
- **点击其他渠道卡片**：无特殊操作，仅显示渠道信息

### 2.3 卡片悬停效果
- **飞猪和携程卡片**：鼠标悬停时显示指针光标，卡片有阴影和过渡效果
- **其他渠道卡片**：鼠标悬停时无特殊效果

## 4. 技术实现

### 4.1 前端框架
- React 18.2.0
- Ant Design 5.12.0
- React Router DOM 6.21.0

### 4.2 组件使用
- Card：用于渠道卡片
- Tabs：用于切换已连接和可连接渠道
- Tag：用于显示渠道状态
- Row/Col：用于布局
- Typography：用于页面标题
- Icon：用于页面标题图标

### 4.3 状态管理
- useState：用于管理渠道数据
  - channels：包含已连接和可连接渠道数据
- useNavigate：用于页面跳转

### 4.4 事件处理
- handleCardClick：处理渠道卡片点击事件
  - 飞猪：跳转到飞猪设置页面
  - 携程：跳转到携程设置页面
  - 其他渠道：无操作

### 4.5 样式实现
- 卡片样式：使用内联样式设置卡片的外观，包括边框、阴影、圆角等
- 背景色：根据渠道名称设置不同的背景色
- 悬停效果：设置卡片的悬停效果，包括阴影和过渡动画
- 图标显示：使用img标签显示渠道图标

## 6. 总结

渠道列表是CRS系统中用于管理酒店销售渠道的功能模块。通过该页面，用户可以查看已连接的渠道和可连接的渠道，并对特定渠道（如飞猪和携程）进行设置。

页面设计清晰，布局合理，使用卡片式布局展示渠道信息，通过不同的背景色和状态标签区分不同渠道的状态。交互流畅，用户可以通过标签页切换不同类型的渠道，点击特定渠道卡片进行设置。

系统支持的渠道包括国内主要OTA平台（携程、飞猪、美团、红色加力）和国际OTA平台（Booking.com、Agoda、Expedia、Hotels.com），为酒店提供了多渠道销售的能力。

未来可以通过后端API获取实时渠道数据，实现更复杂的渠道管理功能，如渠道连接、断开连接、渠道绩效分析等。
