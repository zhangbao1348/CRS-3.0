# 人数差价设置功能分析

## 1. 页面内容

### 1.1 页面标题
- **人数差价设置**：页面顶部显示的标题，带有用户图标

### 1.2 操作按钮
- **保存按钮**：点击保存所有人数差价数据
- **日志按钮**：点击查看操作日志
- **添加差价体系按钮**：点击添加新的差价体系

### 1.3 差价体系标签页
- **标签页标题**：显示差价体系名称，双击可编辑
- **关闭按钮**：点击删除差价体系（至少保留一个）

### 1.4 人数差价表格
- **操作列**：
  - 原始行：显示+按钮，用于添加新的差价行
  - 新增行：显示-按钮，用于删除差价行
- **类型**：人数类型（2成人、3成人、4成人、5成人、额外成人、1儿童、2儿童）
- **值**：差价金额，可编辑
- **起始日期**：差价生效开始日期，可选择
- **结束日期**：差价生效结束日期，可选择
- **星期选择**：金、日、一、二、三、四、五、六，可勾选

### 1.5 操作日志模态框
- **标题**：操作日志
- **表格**：显示操作人、操作时间、操作类型、动作、详细内容

## 2. 交互逻辑

### 2.1 差价体系管理
- **添加差价体系**：点击添加差价体系按钮，创建新的差价体系
- **删除差价体系**：点击标签页关闭按钮，删除对应的差价体系
- **编辑差价体系名称**：双击标签页标题，进入编辑模式，输入新名称，按Enter保存，按Escape取消

### 2.2 人数差价管理
- **添加差价行**：点击+按钮，在当前行后添加新的差价行
- **删除差价行**：点击-按钮，删除当前差价行
- **修改差价值**：在值输入框中输入新的差价金额
- **修改起始日期**：点击日期选择器，选择新的起始日期
- **修改结束日期**：点击日期选择器，选择新的结束日期
- **选择适用星期**：勾选或取消勾选对应的星期

### 2.3 其他操作
- **保存**：点击保存按钮，保存所有人数差价数据，显示保存成功提示
- **查看日志**：点击日志按钮，打开操作日志模态框，显示操作历史

## 4. 技术实现

### 4.1 前端框架
- React 18.2.0
- Ant Design 5.12.0
- dayjs 1.11.19

### 4.2 组件使用
- Typography：用于标题
- Table：用于人数差价表格
- Tabs：用于差价体系标签页
- Button：用于操作按钮
- Input：用于编辑差价值和差价体系名称
- DatePicker：用于选择日期
- Checkbox：用于选择适用星期
- Modal：用于显示操作日志
- Space：用于间距管理
- Icon：用于图标

### 4.3 状态管理
- useState：用于管理组件内部状态
  - pricingSystems：差价体系数据
  - activeSystemId：当前激活的差价体系ID
  - logs：操作日志数据
- useEffect：用于副作用处理

### 4.4 事件处理
- handleSave：处理保存操作
- handleLog：处理查看日志操作
- handleAddSystem：处理添加差价体系操作
- handleDeleteSystem：处理删除差价体系操作
- handleStartEdit：处理开始编辑差价体系名称操作
- handleCancelEdit：处理取消编辑差价体系名称操作
- handleSaveName：处理保存差价体系名称操作
- handleUpdateEditingName：处理更新编辑中的差价体系名称操作
- updateDiffData：处理更新差价数据操作

### 4.5 日志记录
- recordLog：记录操作日志

## 6. 总结

人数差价设置是CRS系统中用于管理不同人数价格差异的功能模块。通过该页面，用户可以创建多个差价体系，为不同人数类型设置不同的差价金额、生效日期和适用星期。

页面设计清晰，功能完整，交互流畅。用户可以通过标签页管理多个差价体系，通过表格编辑每种人数类型的差价信息，通过日志查看操作历史。

系统支持添加和删除差价体系，添加和删除差价行，修改差价值、日期和适用星期等操作，并记录所有操作日志，确保操作可追溯。

未来可以通过后端API获取实时差价数据，实现更复杂的人数差价管理功能，如批量导入/导出、差价规则设置等。
