# 价格查询功能分析

## 1. 页面内容

### 1.1 页面标题
- **价格查询**：页面顶部显示的标题，带有美元图标

### 1.2 搜索筛选区域
- **价格计划选择**：下拉选择框，包含选项：
  - 散客价 (BAR)
  - 协议价 (CORP)
  - 会员价 (MEM)
  - 促销价 (PROMO)
- **月份选择**：月份选择器，用于选择查询的月份
- **查询按钮**：点击执行价格查询操作
- **重置按钮**：点击恢复默认设置

### 1.3 价格表格
- **表头**：
  - 房型：显示房型名称和代码
  - 多人价：显示1人价和2人价
  - 日期列：显示所选月份的所有日期，格式为"MM-DD (星期)"
- **表体**：
  - 按房型分组，每个房型占两行（1人价和2人价）
  - 1人价行：显示酒店价格、携程预测价格（如果启用）、美团预测价格（如果启用）
  - 2人价行：显示酒店价格、携程预测价格（如果启用）、美团预测价格（如果启用）

## 2. 交互逻辑

### 2.1 月份选择
- **选择月份**：点击月份选择器，选择不同的月份
- **自动更新**：选择月份后，表格会自动更新为所选月份的价格
- **日期计算**：系统会自动计算所选月份的天数和对应的星期

### 2.2 价格计划选择
- **选择价格计划**：点击价格计划下拉框，选择不同的价格计划
- **价格更新**：选择价格计划后，需要点击查询按钮才会更新价格

### 2.3 查询功能
- **点击查询按钮**：根据选择的价格计划和月份重新计算并显示价格
- **价格计算**：系统会根据价格计划、房型、日期等因素计算价格

### 2.4 重置功能
- **点击重置按钮**：恢复默认设置，显示当前月份的散客价
- **状态重置**：清空价格计划选择，将月份重置为当前月份

### 2.5 第三方价格显示
- **携程预测价格**：根据系统设置决定是否显示
- **美团预测价格**：根据系统设置决定是否显示

## 4. 技术实现

### 4.1 前端框架
- React 18.2.0
- Ant Design 5.12.0
- dayjs 1.11.19

### 4.2 组件使用
- Card：用于页面内容容器
- Row/Col：用于布局
- Select：用于价格计划选择
- DatePicker：用于月份选择
- Button：用于操作按钮
- Input：用于显示价格
- Table：使用原生表格实现价格表格

### 4.3 状态管理
- useState：用于管理组件内部状态
  - dates：日期数据
  - selectedMonth：选中的月份
  - selectedRatePlan：选中的价格计划
  - roomOnePersonPrices：1人价数据
  - roomTwoPersonPrices：2人价数据
  - ctripOnePersonPrices：携程1人价数据
  - ctripTwoPersonPrices：携程2人价数据
  - meituanOnePersonPrices：美团1人价数据
  - meituanTwoPersonPrices：美团2人价数据
- useEffect：用于副作用处理，如监听存储变化

### 4.4 数据计算
- generateDates：生成所选月份的日期数据
- getPriceData：根据价格计划计算价格数据
  - 基础价格：根据价格计划获取基础价格
  - 房型乘数：根据房型应用价格乘数
  - 周末加价：周末价格乘以1.15的乘数
  - 第三方价格：根据随机因素计算携程和美团的预测价格

### 4.5 事件处理
- handleMonthChange：处理月份变化
- handleSearch：处理查询操作
- handleReset：处理重置操作

## 6. 总结

价格查询是CRS系统中用于查询酒店价格的功能模块。通过该页面，用户可以查看不同月份、不同价格计划下的酒店价格，以及携程和美团的预测价格。

页面设计清晰，功能完整，交互流畅。用户可以通过选择价格计划和月份来查询不同条件下的价格，系统会自动计算并显示详细的价格信息。

价格计算逻辑考虑了多种因素，包括价格计划、房型、日期（周末加价）等，使价格计算更加准确合理。同时，系统还集成了第三方平台的预测价格，为用户提供更全面的价格参考。

未来可以通过后端API获取实时价格数据，实现更复杂的价格查询功能，如多酒店价格对比、历史价格趋势分析等。
