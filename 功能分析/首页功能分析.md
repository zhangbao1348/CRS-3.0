# 首页功能分析

## 1. 页面内容

### 1.1 欢迎区域
- **当前用户**：显示登录用户名称
- **酒店信息**：显示当前酒店名称
- **当前时间**：实时显示系统时间

### 1.2 可用库存
- **房型选择**：下拉选择框，包含全部房型、标准大床房、豪华大床房、标准双床房等选项
- **日期范围选择**：日期选择器，用于选择查看的日期范围
- **查看房价日历按钮**：跳转到房价日历页面
- **库存数据**：显示未来10天的可用房间数量，以卡片形式展示
  - 每个卡片显示日期和可用房间数
  - 当前日期卡片高亮显示

### 1.3 数据概览
- **预订均价**：显示平均预订价格（CNY）
- **平均LOS**：显示平均入住时长
- **平均提前预订时长**：显示平均提前预订天数
- **入住订单数**：显示入住订单数量
- **ADR**：显示平均每日房价（CNY）

### 1.4 预订趋势
- **30天预订趋势图**：折线图显示
  - X轴：日期（30天）
  - Y轴：订单数量
  - 包含平滑曲线和数据点
  - 带有面积填充效果

### 1.5 预订渠道
- **渠道占比图**：柱状图显示
  - X轴：渠道名称（携程、美团、飞猪、Booking.com、Agoda、其他）
  - Y轴：占比百分比
  - 每个柱子显示具体数值

### 1.6 住宿信息
- **当前住宿**：显示当前住宿名称
- **连接状态**：显示连接状态（已连接/未连接）

### 1.7 PMS连接
- **PMS系统**：显示PMS系统名称
- **连接状态**：显示连接状态（已连接/未连接）
- **同步数据按钮**：点击同步PMS系统数据
- **设置按钮**：点击进入PMS设置页面

### 1.8 渠道状态
- **渠道列表**：显示各渠道名称和状态
  - 渠道名称：携程、美团、飞猪、Booking、Agoda
  - 在线状态：显示为绿色或红色状态点
  - 增减库存按钮：每个渠道对应两个按钮，用于调整库存
- **添加渠道按钮**：点击添加新的渠道

### 1.9 平台通知
- **通知列表**：显示系统通知
  - 通知类型：信息、警告、成功
  - 通知标题：显示通知主题
  - 通知内容：显示通知详细信息
  - 通知时间：显示通知发布时间
- **分页控件**：用于浏览更多通知

## 2. 交互逻辑

### 2.1 可用库存
- **点击日期卡片**：查看该日期的详细库存信息
- **选择房型**：筛选显示对应房型的库存信息
- **选择日期范围**：查看指定日期范围的库存信息
- **点击查看房价日历**：跳转到房价日历页面
- **鼠标悬停**：日期卡片会有轻微的上浮和阴影效果

### 2.2 数据概览
- **数据展示**：实时显示最新的统计数据

### 2.3 预订趋势
- **图表交互**：鼠标悬停在数据点上时显示详细信息

### 2.4 预订渠道
- **图表交互**：鼠标悬停在柱子上时显示详细信息

### 2.5 PMS连接
- **点击同步数据**：触发PMS数据同步操作，显示加载状态
- **点击设置**：跳转到PMS设置页面

### 2.6 渠道状态
- **点击增减库存按钮**：调整对应渠道的库存数量
- **点击添加渠道**：打开添加渠道的模态框

### 2.7 平台通知
- **点击通知项**：查看通知详情
- **点击分页控件**：切换到不同页码的通知

## 4. 技术实现

### 4.1 前端框架
- React 18.2.0
- Ant Design 5.12.0
- Ant Design Charts

### 4.2 组件使用
- Card：用于内容区块
- Row/Col：用于布局
- Statistic：用于数据展示
- Table：用于表格数据
- Select：用于下拉选择
- Button：用于操作按钮
- Space：用于间距管理
- Badge：用于状态标识
- List：用于列表展示
- Tag：用于标签展示
- Progress：用于进度展示
- Tabs：用于标签页
- DatePicker：用于日期选择
- Typography：用于文本展示
- Line/Bar：用于图表展示

### 4.3 状态管理
- useState：用于管理组件内部状态
- useEffect：用于副作用处理，如初始化数据加载

### 4.4 数据获取
- 模拟数据：当前使用前端模拟数据
- 未来实现：通过API从后端获取实时数据

## 5. 总结

首页作为CRS系统的入口页面，提供了全面的系统概览和关键数据展示。通过合理的布局和交互设计，用户可以快速了解酒店的运营状态，包括预订情况、库存状态、渠道状态等。页面采用响应式设计，适配不同屏幕尺寸，确保在各种设备上都能良好展示。

首页的功能模块设计清晰，数据可视化效果良好，交互流畅，为用户提供了直观、高效的操作体验。
