# 渠道映射功能分析

## 1. 页面内容

### 1.1 页面标题
- **渠道映射**：页面顶部显示的标题，带有链接图标

### 1.2 筛选区域
- **渠道选择**：下拉选择框，包含选项：
  - 携程
  - 飞猪
  - 美团
  - 红色加力
- **酒店选择**：下拉选择框，包含选项：
  - 上海宝丽嘉酒店
  - 杭州钓美酒店
  - 北京王府井酒店
  - 深圳南山酒店
- **新增映射按钮**：点击打开新增映射模态框

### 1.3 批量操作区域
- **已选择项显示**：显示已选择的记录数量
- **批量设置按钮**：点击打开批量设置模态框
- **批量启用按钮**：批量启用选中的记录
- **批量禁用按钮**：批量禁用选中的记录
- **批量删除按钮**：批量删除选中的记录
- **取消选择按钮**：取消所有选中的记录

### 1.4 标签页
- **酒店CODE映射**：显示酒店与渠道的CODE映射
- **房型CODE映射**：显示房型与渠道的CODE映射
- **房价CODE映射**：显示房价码与渠道的CODE映射

### 1.5 酒店CODE映射表格
- **渠道**：显示渠道名称
- **酒店名称**：显示酒店名称
- **酒店CODE**：显示酒店的CODE，蓝色标签
- **渠道酒店CODE**：显示渠道中酒店的CODE，橙色标签
- **状态**：显示启用/禁用状态，可点击切换
- **更新时间**：显示最后更新时间
- **操作**：编辑和删除按钮

### 1.6 房型CODE映射表格
- **渠道**：显示渠道名称
- **酒店**：显示酒店名称
- **酒店房型**：显示酒店房型名称
- **房型CODE**：显示房型的CODE，蓝色标签
- **渠道房型名称**：显示渠道中房型的名称
- **渠道房型CODE**：显示渠道中房型的CODE，橙色标签
- **状态**：显示启用/禁用状态，可点击切换
- **更新时间**：显示最后更新时间
- **操作**：编辑和删除按钮

### 1.7 房价CODE映射表格
- **渠道**：显示渠道名称
- **酒店**：显示酒店名称
- **房价码名称**：显示房价码的名称
- **房价CODE**：显示房价码的CODE，蓝色标签
- **渠道房价名称**：显示渠道中房价的名称
- **渠道房价CODE**：显示渠道中房价的CODE，橙色标签
- **加价率(%)**：显示加价率，红色表示正值，绿色表示零
- **状态**：显示启用/禁用状态，可点击切换
- **更新时间**：显示最后更新时间
- **操作**：编辑和删除按钮

### 1.8 新增/编辑模态框
- **渠道**：下拉选择框
- **酒店**：下拉选择框
- **酒店CODE映射**：
  - 渠道酒店CODE：输入框
- **房型CODE映射**：
  - 酒店房型：下拉选择框
  - 渠道房型CODE：输入框
  - 渠道房型名称：输入框
- **房价CODE映射**：
  - 房价码：下拉选择框
  - 渠道房价CODE：输入框
  - 渠道房价名称：输入框
  - 加价率(%)：数字输入框

### 1.9 批量设置模态框
- **渠道CODE前缀**：输入框，生成格式为"前缀_原CODE"
- **房型CODE映射**：
  - 渠道房型名称：输入框
- **房价CODE映射**：
  - 渠道房价名称：输入框
  - 加价率(%)：数字输入框

## 2. 交互逻辑

### 2.1 筛选功能
- **选择渠道**：根据选择的渠道筛选映射数据
- **选择酒店**：根据选择的酒店筛选映射数据
- **组合筛选**：同时根据渠道和酒店筛选映射数据

### 2.2 新增映射
- **点击新增映射按钮**：打开新增映射模态框
- **填写表单**：根据当前标签页填写对应的表单
- **点击保存**：保存新的映射记录，关闭模态框，显示成功消息

### 2.3 编辑映射
- **点击编辑按钮**：打开编辑映射模态框，填充当前记录的数据
- **修改表单**：修改表单数据
- **点击保存**：更新映射记录，关闭模态框，显示成功消息

### 2.4 删除映射
- **点击删除按钮**：弹出确认对话框
- **点击确定**：删除映射记录，显示成功消息

### 2.5 切换状态
- **点击状态标签**：切换映射记录的状态（启用/禁用），显示成功消息

### 2.6 批量操作
- **选择记录**：在表格中选择多条记录
- **批量设置**：点击批量设置按钮，打开批量设置模态框，设置批量操作参数，点击批量设置按钮执行操作
- **批量启用**：点击批量启用按钮，启用选中的记录，显示成功消息
- **批量禁用**：点击批量禁用按钮，禁用选中的记录，显示成功消息
- **批量删除**：点击批量删除按钮，弹出确认对话框，点击确定删除选中的记录，显示成功消息
- **取消选择**：点击取消选择按钮，取消所有选中的记录

### 2.7 标签页切换
- **点击标签页**：切换不同类型的映射（酒店、房型、房价码）

### 4.1 前端框架

### 4.2 组件使用
- Card：用于页面内容容器

### 4.3 状态管理

## 6. 总结

渠道映射是CRS系统中用于管理酒店、房型、房价码与各销售渠道之间映射关系的功能模块。通过该页面，用户可以创建、编辑、删除和管理这些映射关系，确保系统能够正确地与各渠道进行数据交互。

页面设计清晰，功能完整，交互流畅。用户可以通过标签页切换不同类型的映射，通过筛选条件快速找到需要的映射记录，通过批量操作提高管理效率。

系统支持对酒店、房型和房价码的映射管理，每个映射都包含详细的信息，如渠道CODE、状态、更新时间等。用户可以根据需要启用或禁用映射，灵活管理不同渠道的销售策略。

未来可以通过后端API获取实时映射数据，实现更复杂的渠道映射功能，如映射关系的版本控制、映射历史记录、渠道API集成测试等。
