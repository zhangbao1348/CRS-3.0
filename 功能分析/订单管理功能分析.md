# 订单管理功能分析

## 1. 页面内容

### 1.1 页面标题
- **订单**：页面顶部显示的标题

### 1.2 搜索区域
- **订单号输入框**：用于输入订单号进行搜索
- **状态选择下拉框**：包含选项：
  - 所有状态
  - 已确认
  - 已取消
  - 取消失败
  - 已入住
  - 已离店
- **渠道选择下拉框**：包含选项：
  - 所有渠道
  - 携程
  - 飞猪
  - 美团
  - PMS
- **入住人输入框**：用于输入入住人姓名进行搜索
- **搜索按钮**：点击执行搜索操作
- **重置按钮**：点击清空所有搜索条件
- **导出按钮**：点击导出订单数据

### 1.3 订单列表
- **全选复选框**：用于选择所有订单
- **订单号**：
  - 渠道订单号
  - CRS订单号
  - PMS订单号
  - 人工干预标记（如果有）
- **状态**：订单状态（已确认、已取消、取消失败等），显示为不同颜色的标签
- **渠道**：预订渠道（携程、美团、飞猪等），带有渠道图标
- **预订时间**：订单预订时间
- **住宿日期**：入住日期 ~ 退房日期
- **入住人**：入住人姓名
- **总房价**：订单总房价（CNY）
- **操作**：查看按钮

## 2. 交互逻辑

### 2.1 搜索功能
- **输入订单号**：按订单号筛选订单
- **选择状态**：按订单状态筛选订单
- **选择渠道**：按预订渠道筛选订单
- **输入入住人**：按入住人姓名筛选订单
- **点击搜索按钮**：执行搜索操作，显示加载状态，搜索完成后显示符合条件的订单
- **点击重置按钮**：清空所有搜索条件，恢复默认状态
- **点击导出按钮**：导出订单数据（当前显示为开发中状态）

### 2.2 订单操作
- **点击查看按钮**：跳转到订单详情页面

### 2.3 订单列表
- **点击全选复选框**：选择所有订单
- **悬停订单号**：显示完整的订单号信息
- **状态标签**：不同状态显示不同颜色
  - 已确认：绿色
  - 已取消：绿色
  - 取消失败：红色
- **人工干预标记**：显示为红色徽章，标记人工干预过的订单

## 4. 技术实现

### 4.1 前端框架
- React 18.2.0
- Ant Design 5.12.0
- React Router DOM

### 4.2 组件使用
- Card：用于内容区块
- Typography：用于文本展示
- Form：用于搜索表单
- Input：用于输入框
- Select：用于下拉选择
- Button：用于操作按钮
- Table：用于订单列表
- Space：用于间距管理
- Tag：用于状态标签
- Checkbox：用于选择框
- message：用于消息提示
- Badge：用于标记
- Icon：用于图标

### 4.3 状态管理
- useState：用于管理组件内部状态
  - form：表单实例
  - loading：加载状态
  - orderData：订单数据
- useNavigate：用于页面跳转

### 4.4 数据获取
- 模拟数据：当前使用前端模拟数据
- 未来实现：通过API从后端获取实时数据

### 4.5 事件处理
- handleSearch：处理搜索操作
- handleReset：处理重置操作
- handleExport：处理导出操作
- handleViewOrder：处理查看订单操作

## 6. 总结

订单管理页面是CRS系统中用于管理酒店预订订单的核心功能模块。通过该页面，用户可以查看、搜索和管理所有的预订订单，包括订单状态、渠道、预订时间、住宿日期、入住人、总房价等详细信息。

页面设计清晰，功能完整，交互流畅。搜索区域提供了多种筛选条件，方便用户快速找到需要的订单。订单列表展示了详细的订单信息，通过颜色和图标区分不同的状态和渠道，提高了信息的可读性。

未来可以通过后端API获取实时数据，实现更复杂的订单管理功能，如订单修改、取消、确认等操作，以及更详细的订单详情页面。
