# 房型管理功能分析

## 1. 页面内容

### 1.1 页面标题
- **房型管理**：页面顶部显示的标题

### 1.2 查询表单
- **代码输入框**：用于输入房型代码进行搜索
- **名称输入框**：用于输入房型名称进行搜索
- **查询按钮**：点击执行搜索操作
- **重置按钮**：点击清空搜索条件
- **新增按钮**：点击打开新增房型模态框

### 1.3 房型列表
- **代码**：房型代码
- **名称**：房型中文名称
- **英文名称**：房型英文名称
- **房型数量**：该房型的房间数量
- **面积**：房型面积（平方米）
- **楼层**：房型所在楼层
- **窗型**：房型的窗型（有窗/无窗）
- **操作**：编辑按钮

### 1.4 新增/编辑模态框
- **房型代码**：输入房型代码（必填）
- **房型中文名称**：输入房型中文名称（必填）
- **房型英文名称**：输入房型英文名称
- **房型数量**：输入房型数量（必填）
- **房型面积**：输入房型面积
- **所在楼层**：输入房型所在楼层
- **最大入住成人数**：输入最大入住成人数（必填）
- **最大入住人数**：输入最大入住人数
- **窗型**：选择窗型（有窗/无窗）（必填）
- **床型**：选择床型（1张1.8米大床、2张1.2米单人床、1张1.5米大床、3张1.2米单人床）（必填）
- **图片**：上传房型图片
- **确认按钮**：保存房型信息
- **取消按钮**：取消操作

## 2. 交互逻辑

### 2.1 搜索功能
- **输入代码**：按房型代码筛选
- **输入名称**：按房型名称筛选
- **点击查询按钮**：执行搜索操作，显示符合条件的房型
- **点击重置按钮**：清空搜索条件，显示所有房型

### 2.2 新增功能
- **点击新增按钮**：打开新增房型模态框
- **填写表单**：输入房型的各项信息
- **点击确认按钮**：保存新房型，显示成功消息，关闭模态框
- **点击取消按钮**：取消操作，关闭模态框

### 2.3 编辑功能
- **点击编辑按钮**：打开编辑房型模态框，显示当前房型信息
- **修改表单**：修改房型的各项信息
- **点击确认按钮**：保存修改，显示成功消息，关闭模态框
- **点击取消按钮**：取消操作，关闭模态框

### 2.4 数据加载
- **页面加载**：自动加载房型数据
- **选择酒店变化**：重新加载对应酒店的房型数据
- **加载状态**：显示加载动画

## 4. 技术实现

### 4.1 前端框架
- React 18.2.0
- Ant Design 5.12.0
- Axios 1.13.3

### 4.2 组件使用
- Button：用于操作按钮
- Input：用于输入框
- Table：用于房型列表
- Modal：用于新增/编辑模态框
- Form：用于表单
- Select：用于下拉选择
- Upload：用于图片上传
- Space：用于间距管理
- Spin：用于加载动画
- message：用于消息提示
- Icon：用于图标

### 4.3 状态管理
- useState：用于管理组件内部状态
  - roomTypes：房型数据
  - filteredRoomTypes：筛选后的房型数据
  - isModalVisible：模态框显示状态
  - isEditMode：是否为编辑模式
  - loading：加载状态
  - form：表单实例
  - selectedRoomType：当前选中的房型
- useHotelContext：用于获取选中的酒店
- useEffect：用于副作用处理，如数据加载

### 4.4 数据获取
- 模拟数据：当未选择酒店或API调用失败时使用
- API调用：从后端获取房型数据
  - GET /api/hotel-room-types/hotel/{hotelId}：获取指定酒店的房型
  - POST /api/hotel-room-types：新增房型
  - PUT /api/hotel-room-types/{id}：编辑房型

### 4.5 事件处理
- handleSearch：处理搜索操作
- handleAdd：处理新增按钮点击
- handleEdit：处理编辑按钮点击
- handleSave：处理保存操作

## 6. 总结

房型管理是CRS系统中用于管理酒店房型信息的功能模块。通过该页面，用户可以查看、搜索、新增和编辑酒店的房型信息。

页面设计清晰，功能完整，交互流畅。查询表单提供了按代码和名称搜索房型的功能，房型列表展示了详细的房型信息，模态框操作简单直观，确保用户可以快速完成房型的新增和编辑。

系统支持上传房型图片，为房型提供更直观的展示。同时，通过HotelContext获取当前选中的酒店，确保房型数据与酒店关联。

未来可以通过后端API获取实时房型数据，实现更复杂的房型管理功能，如房型删除、批量操作等。
