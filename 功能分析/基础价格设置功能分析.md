# 基础价格设置功能分析

## 1. 页面内容

### 1.1 页面标题
- **基础价格设置**：页面顶部显示的标题，带有美元符号图标

### 1.2 价格类型标签页
- **门市价(BAR)**：默认选中的标签页
- **大客户固定价(SCAS)**：大客户固定价格设置
- **大客户双早(SCASBB)**：大客户双早价格设置

### 1.3 日期选择和操作按钮
- **日期范围选择器**：选择价格设置的日期范围
- **查询按钮**：点击执行查询操作
- **批量修改按钮**：点击打开批量修改价格模态框
- **日志按钮**：点击查看操作日志

### 1.4 价格表格
- **表头**：显示日期和星期
- **基准价格行**：
  - 1人价：可编辑的输入框
  - 2人价：根据1人价自动计算，只读
- **房型价格行**：
  - 每个房型显示两行（1人价和2人价）
  - 1人价：根据基准价格和房型系数自动计算，只读
  - 2人价：根据1人价自动计算，只读
  - 携程预测价格：根据房型价格自动生成，可选显示
  - 美团预测价格：根据房型价格自动生成，可选显示

### 1.5 批量修改模态框
- **日期设置**：
  - 开始日期选择器
  - 结束日期选择器
  - 增加日期段按钮
  - 删除日期段按钮
- **周控设置**：
  - 全选复选框
  - 周一至周日复选框
- **价格设置**：
  - 价格设置类型选择（直接设置、增加固定值、减少固定值、增加百分比、减少百分比）
  - 价格值输入框
- **保存按钮**：保存批量修改
- **取消按钮**：取消批量修改

## 2. 交互逻辑

### 2.1 日期选择
- **选择日期范围**：点击日期选择器，选择开始和结束日期，系统自动生成日期数组和价格数据

### 2.2 基准价格修改
- **修改1人价**：在基准价格1人价输入框中输入新的价格，系统自动计算：
  - 基准价格2人价（1人价 * 1.07）
  - 各房型1人价（基准价格 * 房型系数）
  - 各房型2人价（房型1人价 * 1.07）
  - 携程和美团预测价格

### 2.3 批量修改
- **打开批量修改模态框**：点击批量修改按钮
- **添加日期段**：点击增加日期段按钮，添加新的日期范围
- **删除日期段**：点击删除按钮，删除对应的日期范围
- **选择周控**：勾选或取消勾选对应的星期
- **选择价格设置类型**：选择价格设置的类型（直接设置、增加固定值等）
- **输入价格值**：输入价格设置的数值
- **保存批量修改**：点击保存按钮，系统根据设置修改指定日期和星期的价格
- **取消批量修改**：点击取消按钮，关闭模态框

### 2.4 其他操作
- **查询**：点击查询按钮，查询价格数据
- **查看日志**：点击日志按钮，查看操作历史

### 5.2 价格计算逻辑
- 基准价格2人价 = 基准价格1人价 * 1.07
- 房型1人价 = 基准价格1人价 * 房型系数
- 房型2人价 = 房型1人价 * 1.07
- 携程预测价格 = 房型价格 * (0.80 - 0.92随机值)
- 美团预测价格 = 房型价格 * (0.78 - 0.92随机值)

## 6. 总结

基础价格设置是CRS系统中用于管理酒店基础价格的功能模块。通过该页面，用户可以设置基准价格和各房型价格，并自动计算携程和美团的预测价格。

页面设计清晰，功能完整，交互流畅。用户可以通过日期范围选择器选择价格设置的日期范围，通过基准价格输入框设置基础价格，系统会自动计算各房型的价格和预测价格。

批量修改功能允许用户同时修改多个日期和星期的价格，支持多种价格设置方式，提高了价格管理的效率。

系统支持显示携程和美团的预测价格，为用户提供价格参考，帮助用户做出更合理的价格决策。

未来可以通过后端API获取实时价格数据，实现更复杂的价格管理功能，如价格历史记录、价格趋势分析等。
