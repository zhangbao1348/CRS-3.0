# 包价设置功能分析

## 1. 页面内容

### 1.1 页面标题
- **包价设置**：页面顶部显示的标题，带有礼物图标

### 1.2 搜索筛选区域
- **包价名称输入框**：用于输入包价名称进行搜索
- **包价代码输入框**：用于输入包价代码进行搜索
- **包价类型选择**：下拉选择框，包含选项：
  - 早餐
  - 午餐
  - 晚餐
  - 下午茶
  - 门票
  - 其他
- **状态选择**：下拉选择框，包含选项：
  - 启用
  - 停用
- **重置按钮**：点击清空搜索条件
- **搜索按钮**：点击执行搜索操作

### 1.3 操作按钮区域
- **新增包价按钮**：点击跳转到新增包价页面

### 1.4 包价列表
- **包价名称**：包价的中文名称
- **包价代码**：包价的代码
- **包价类型**：包价的类型
- **包价价格**：包价的价格
- **描述**：包价的详细描述
- **状态**：包价的状态（启用/停用），显示为不同颜色的文本
- **操作**：编辑按钮

## 2. 交互逻辑

### 2.1 搜索功能
- **输入包价名称**：按包价名称筛选
- **输入包价代码**：按包价代码筛选
- **选择包价类型**：按包价类型筛选
- **选择状态**：按包价状态筛选
- **点击重置按钮**：清空所有搜索条件，显示所有包价
- **点击搜索按钮**：执行搜索操作，显示符合条件的包价

### 2.2 新增功能
- **点击新增包价按钮**：跳转到新增包价页面

### 2.3 编辑功能
- **点击编辑按钮**：跳转到编辑包价页面

### 2.4 数据加载
- **页面加载**：自动加载包价列表
- **搜索操作**：重新加载符合条件的包价列表
- **加载状态**：显示加载动画

## 4. 技术实现

### 4.1 前端框架
- React 18.2.0
- Ant Design 5.12.0
- React Router DOM 6.21.0
- Axios 1.13.3

### 4.2 组件使用
- Card：用于搜索筛选区域
- Row/Col：用于布局
- Input：用于输入框
- Select：用于下拉选择
- Button：用于操作按钮
- Table：用于包价列表
- Space：用于间距管理
- message：用于消息提示
- Icon：用于图标

### 4.3 状态管理
- useState：用于管理组件内部状态
  - packages：包价数据
  - loading：加载状态
  - searchParams：搜索参数
- useNavigate：用于页面跳转
- useEffect：用于副作用处理，如数据加载

### 4.4 数据获取
- 模拟数据：当前使用前端模拟数据
- 未来实现：通过API从后端获取实时数据

### 4.5 事件处理
- fetchPackages：获取包价列表
- handleSearch：处理搜索操作
- handleReset：处理重置操作
- handleAddPackage：处理新增包价操作
- handleEditPackage：处理编辑包价操作

## 6. 总结

包价设置是CRS系统中用于管理酒店包价的功能模块。通过该页面，用户可以查看、搜索、新增和编辑酒店的包价信息。

页面设计清晰，功能完整，交互流畅。搜索筛选区域提供了多种筛选条件，方便用户快速找到需要的包价。包价列表展示了详细的包价信息，包括名称、代码、类型、价格、描述和状态等。

系统通过颜色区分包价的状态，启用状态显示为绿色，停用状态显示为红色，提高了信息的可读性。

未来可以通过后端API获取实时包价数据，实现更复杂的包价管理功能，如包价删除、批量操作等。
