# 房控日历功能分析

## 1. 页面内容

### 1.1 页面标题
- **房控日历**：页面顶部显示的标题，带有日历图标

### 1.2 标签页
- **主要房控日历**：默认选中的标签页
- **PMS房控日历**：显示PMS系统的房控信息
- **酒店超预订管理**：设置酒店级别的超预订策略
- **房型超预订管理**：设置房型级别的超预订策略
- **房价级房量管理**：管理不同价格级别的房量
- **渠道级房量管理**：管理不同渠道的房量
- **市场码级房量管理**：管理不同市场码的房量
- **渠道+房型级房量**：管理不同渠道和房型组合的房量

### 1.3 主要房控日历
- **控制类型选择**：下拉选择框，包含选项：
  - 携程
  - 美团
  - 艺龙
  - 飞猪
  - 其他
- **库存类型选择**：下拉选择框，包含选项：
  - 库存
  - 房价
  - 开关房
- **房型选择**：下拉选择框，包含选项：
  - 全部房型
  - 标准大床房
  - 豪华大床房
  - 标准双床房
  - 等其他房型
- **价格计划选择**：下拉选择框，包含选项：
  - 全部价格计划
  - 牌价
  - OTA价
  - 会员价
- **筛选按钮**：点击执行筛选操作
- **刷新按钮**：点击刷新数据
- **月份切换**：上月、当月、下月按钮

### 1.4 房控日历表格
- **表头**：
  - 左侧：房型代码、房型名称
  - 顶部：日期（月份、日期、星期）
- **表格内容**：
  - **库存视图**：显示可售数量和已售数量
  - **房价视图**：显示不同价格计划的房价
  - **开关房视图**：显示房间的开关状态

### 1.5 模态框
- **更新房价模态框**：
  - 标题：更新房价
  - 房价输入框：输入新的房价
  - 确认按钮：保存更新
  - 取消按钮：取消操作
- **更新库存模态框**：
  - 标题：更新库存
  - 可售数量输入框：输入新的可售数量
  - 已订数量输入框：输入新的已订数量
  - 确认按钮：保存更新
  - 取消按钮：取消操作

## 2. 交互逻辑

### 2.1 标签页切换
- **点击标签页**：切换到对应的功能页面

### 2.2 主要房控日历
- **选择控制类型**：切换不同渠道的房控信息
- **选择库存类型**：切换显示库存、房价或开关房状态
- **选择房型**：筛选显示对应房型的信息
- **选择价格计划**：筛选显示对应价格计划的信息
- **点击筛选按钮**：执行筛选操作
- **点击刷新按钮**：刷新数据，显示成功消息
- **点击月份切换按钮**：切换到上月或下月

### 2.3 房控日历表格
- **点击日期单元格**：
  - 库存视图：弹出更新库存模态框
  - 房价视图：弹出更新房价模态框
  - 开关房视图：弹出更新开关房状态模态框
- **悬停日期单元格**：显示详细信息

### 2.4 模态框操作
- **输入房价**：在更新房价模态框中输入新的房价
- **输入库存数量**：在更新库存模态框中输入新的可售数量和已订数量
- **点击确认按钮**：保存更新，显示成功消息，关闭模态框
- **点击取消按钮**：取消操作，关闭模态框

## 4. 技术实现

### 4.1 前端框架
- React 18.2.0
- Ant Design 5.12.0

### 4.2 组件使用
- Card：用于内容区块
- Tabs：用于标签页
- Select：用于下拉选择
- Button：用于操作按钮
- Table：用于房控日历表格
- Modal：用于弹出模态框
- Form：用于表单
- Input：用于输入框
- InputNumber：用于数字输入
- message：用于消息提示
- Icon：用于图标

### 4.3 状态管理
- useState：用于管理组件内部状态
  - dates：日期数据
  - roomTypes：房型数据
  - inventoryData：库存/房价/开关房数据
  - selectedRoomType：选中的房型
  - selectedPricePlan：选中的价格计划
  - selectedControlType：选中的控制类型
  - selectedInventoryType：选中的库存类型
  - isModalVisible：模态框显示状态
  - currentRow：当前操作的行数据
  - currentDate：当前操作的日期
  - form：表单实例
- useEffect：用于副作用处理，如初始化数据加载

### 4.4 数据获取
- 模拟数据：当前使用前端模拟数据
- 未来实现：通过API从后端获取实时数据

### 4.5 事件处理
- handleUpdateInventory：处理库存更新
- handleUpdatePrice：处理房价更新
- handleSubmit：处理模态框提交
- handleRefresh：处理刷新操作
- handleRoomTypeSwitchChange：处理房型分配开关变化
- handleRateCodeSwitchChange：处理房价码分配开关变化

## 6. 总结

房控日历是CRS系统中用于管理酒店房间库存和价格的核心功能模块。通过该页面，用户可以查看和管理不同房型、不同渠道、不同价格计划的库存和价格信息，以及设置超预订策略。

页面设计清晰，功能完整，交互流畅。通过标签页切换不同的功能模块，通过下拉选择框筛选不同的条件，通过点击日期单元格更新库存或价格信息。

房控日历表格支持多种视图模式，包括库存视图、房价视图和开关房视图，满足不同的管理需求。模态框操作简单直观，确保用户可以快速完成库存和价格的更新。

未来可以通过后端API获取实时数据，实现更复杂的房控功能，如批量更新、价格规则设置等。
