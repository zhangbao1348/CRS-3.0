根据集团管理的菜单结构，我将更新数据库表设计，包含集团管理的所有功能模块：

## 集团管理功能分析
1. **集团管理**：管理集团基本信息
2. **酒店管理**：管理集团下的酒店
3. **集团房型管理**：管理集团级别的房型模板
4. **集团房价码管理**：管理集团级别的房价码模板
5. **市场码管理**：管理全局市场码
6. **渠道码管理**：管理全局渠道码
7. **来源码管理**：管理全局来源码
8. **税率设置**：管理全局税率
9. **包价设置**：管理全局包价
10. **集团担保政策管理**：管理集团级担保政策
11. **集团取消政策管理**：管理集团级取消政策

## 更新后的表结构设计

### 1. 集团表（groups）
- **用途**：存储集团基本信息
- **关键字段**：
  - id (PK)
  - group_code (唯一标识)
  - group_name
  - description
  - status (active/inactive)

### 2. 酒店表（hotels）
- **用途**：存储酒店基本信息
- **关键字段**：
  - id (PK)
  - hotel_code (唯一标识)
  - group_id (FK to groups)
  - chinese_name
  - english_name
  - star_rating
  - province
  - city
  - address
  - longitude
  - latitude
  - phone
  - email
  - introduction
  - status (active/inactive)

### 3. 集团房型表（group_room_types）
- **用途**：存储集团级别的房型模板
- **关键字段**：
  - id (PK)
  - group_id (FK to groups)
  - room_type_code (唯一标识)
  - room_type_name
  - description
  - status (active/inactive)

### 4. 集团房价码表（group_rate_codes）
- **用途**：存储集团级别的房价码模板
- **关键字段**：
  - id (PK)
  - group_id (FK to groups)
  - rate_code (唯一标识)
  - rate_name
  - description
  - status (active/inactive)

### 5. 房型表（room_types）
- **用途**：存储酒店实际使用的房型
- **关键字段**：
  - id (PK)
  - hotel_id (FK to hotels)
  - group_room_type_id (FK to group_room_types)
  - code (唯一标识)
  - name
  - description
  - status (active/inactive)

### 6. 市场码表（market_codes）
- **用途**：存储全局市场码
- **关键字段**：
  - id (PK)
  - code (唯一标识)
  - name
  - description
  - status (active/inactive)

### 7. 渠道码表（channel_codes）
- **用途**：存储全局渠道码
- **关键字段**：
  - id (PK)
  - code (唯一标识)
  - name
  - description
  - status (active/inactive)

### 8. 来源码表（source_codes）
- **用途**：存储全局来源码
- **关键字段**：
  - id (PK)
  - code (唯一标识)
  - name
  - description
  - status (active/inactive)

### 9. 税率设置表（tax_settings）
- **用途**：存储全局税率设置
- **关键字段**：
  - id (PK)
  - tax_type (room/tax/fee)
  - tax_name
  - tax_rate (decimal)
  - description
  - status (active/inactive)

### 10. 包价表（packages）
- **用途**：存储全局包价
- **关键字段**：
  - id (PK)
  - code (唯一标识)
  - name
  - description
  - status (active/inactive)

### 11. 集团担保政策表（group_guarantee_policies）
- **用途**：存储集团级担保政策
- **关键字段**：
  - id (PK)
  - group_id (FK to groups)
  - policy_code (唯一标识)
  - policy_name
  - policy_details (text)
  - status (active/inactive)

### 12. 集团取消政策表（group_cancellation_policies）
- **用途**：存储集团级取消政策
- **关键字段**：
  - id (PK)
  - group_id (FK to groups)
  - policy_code (唯一标识)
  - policy_name
  - policy_details (text)
  - status (active/inactive)

### 13. 更新价格计划表（rate_plans）
- **新增关键字段**：
  - hotel_id (FK to hotels)
  - guarantee_policy_id (FK to group_guarantee_policies)
  - cancellation_policy_id (FK to group_cancellation_policies)
  - market_code_id (FK to market_codes)
  - channel_code_id (FK to channel_codes)
  - source_code_id (FK to source_codes)

### 14. 更新房型差价体系表（room_type_diff_systems）
- **新增关键字段**：
  - hotel_id (FK to hotels)

### 15. 更新人数差价体系表（person_diff_systems）
- **新增关键字段**：
  - hotel_id (FK to hotels)

### 16. 更新基础价格表（base_prices）
- **新增关键字段**：
  - hotel_id (FK to hotels)

### 17. 更新库存表（inventory）
- **新增关键字段**：
  - hotel_id (FK to hotels)

## 表关系说明
1. 一个集团可包含多个酒店
2. 一个酒店属于一个集团
3. 一个集团可包含多个集团房型
4. 一个酒店可使用多个集团房型作为模板
5. 一个集团可包含多个集团房价码
6. 价格计划关联酒店、市场码、渠道码、来源码
7. 价格计划关联集团担保政策和取消政策
8. 差价体系关联酒店
9. 基础价格和库存关联酒店

## 设计特点
1. 支持集团-酒店层级管理
2. 支持集团级模板复用
3. 支持全局配置管理
4. 完善的状态管理
5. 良好的扩展性
6. 支持多集团、多酒店架构

## 实现方式
使用SQL CREATE TABLE语句创建上述表结构，添加必要的主键、外键、唯一约束和索引，确保数据完整性和查询性能。
