# 实现3级树状结构管理页面

## 需求分析
将市场码、渠道码、来源码页面实现为3级树状结构，支持：
- 新增、修改、删除节点
- 维护节点的CODE和名称
- 3级树状展示

## 技术方案

### 数据结构设计
```javascript
const treeData = [
  {
    key: '1',
    title: '节点名称',
    code: 'CODE001',
    children: [
      {
        key: '1-1',
        title: '子节点1',
        code: 'CODE001-1',
        children: [
          {
            key: '1-1-1',
            title: '子子节点1',
            code: 'CODE001-1-1'
          }
        ]
      }
    ]
  }
]
```

### 页面布局设计
1. **顶部操作区**：新增按钮、刷新按钮
2. **树状展示区**：使用Ant Design Tree组件展示3级树结构
3. **右侧详情区**：显示选中节点的详情信息
4. **编辑弹窗**：新增/修改节点的表单

### 功能实现

#### 1. 树状展示
- 使用Ant Design Tree组件
- 支持节点展开/折叠
- 支持节点选中
- 显示节点名称和CODE

#### 2. 新增功能
- 支持在根节点新增
- 支持在选中节点下新增子节点
- 支持新增1级、2级、3级节点
- 弹出表单，填写CODE和名称

#### 3. 修改功能
- 支持修改节点的CODE和名称
- 弹出表单，修改选中节点的信息

#### 4. 删除功能
- 支持删除选中节点
- 删除前弹出确认对话框
- 删除时级联删除子节点

#### 5. 表单验证
- CODE必填且唯一
- 名称必填
- CODE格式验证
