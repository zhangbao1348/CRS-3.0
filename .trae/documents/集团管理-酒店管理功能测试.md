# 集团管理-酒店管理功能测试用例

## 测试目标
对集团管理-酒店管理功能进行完整的测试，包含增删改查操作，确保功能正常运行。

## 测试环境
- 前端服务：http://localhost:3000/
- 后端服务：http://localhost:8080/
- 数据库：MySQL (CRS数据库)

## 测试用例

### 1. 酒店列表查询测试
- **测试步骤**：
  1. 访问集团管理-酒店管理页面
  2. 检查酒店列表是否正常显示
  3. 验证分页功能
  4. 验证搜索筛选功能
- **预期结果**：
  - 酒店列表正常显示所有酒店信息
  - 分页功能正常工作
  - 搜索筛选功能可以根据条件过滤酒店

### 2. 新增酒店测试
- **测试步骤**：
  1. 点击"新增酒店"按钮
  2. 填写酒店基本信息（酒店代码、名称、地址等）
  3. 配置酒店设施
  4. 上传酒店图片
  5. 设置酒店管控（分配房价码、房型）
  6. 提交保存
- **预期结果**：
  - 酒店成功创建
  - 跳转到酒店列表页面
  - 新酒店出现在列表中

### 3. 编辑酒店测试
- **测试步骤**：
  1. 在酒店列表中选择一个酒店
  2. 点击"编辑"按钮
  3. 修改酒店信息
  4. 保存修改
- **预期结果**：
  - 酒店信息成功更新
  - 跳转到酒店列表页面
  - 酒店信息显示为修改后的值

### 4. 删除酒店测试
- **测试步骤**：
  1. 在酒店列表中选择一个酒店
  2. 点击"删除"按钮
  3. 确认删除操作
- **预期结果**：
  - 酒店成功删除
  - 酒店从列表中移除
  - 显示删除成功提示

### 5. 查看酒店详情测试
- **测试步骤**：
  1. 在酒店列表中选择一个酒店
  2. 点击酒店名称或查看按钮
  3. 检查酒店详情信息
- **预期结果**：
  - 酒店详情模态框正常显示
  - 酒店所有信息完整展示
  - 标签页切换正常
