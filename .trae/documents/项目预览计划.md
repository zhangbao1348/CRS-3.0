# 项目预览计划

## 目标
启动前端开发服务器并预览CRS项目，确保项目能够正常运行和访问。

## 步骤

### 1. 启动前端开发服务器
- 执行 `npm run dev` 命令启动Vite开发服务器
- 等待服务器启动完成
- 记录服务器运行端口（通常为3000或3001）

### 2. 检查后端服务状态
- 检查Spring Boot后端服务是否正在运行
- 如果后端服务未运行，启动后端服务

### 3. 预览项目
- 打开浏览器访问前端开发服务器地址
- 验证项目是否正常加载
- 检查主要功能模块是否可访问
- 验证前端与后端的连接是否正常

### 4. 测试关键功能
- 测试集团管理-酒店管理功能
- 验证页面导航和路由是否正常
- 检查API调用是否成功

## 预期结果
- 前端开发服务器成功启动
- 项目页面正常加载
- 主要功能模块可访问
- 前端与后端连接正常
- 项目预览成功完成
