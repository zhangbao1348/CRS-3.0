# 完善后端代码以满足前端功能需求

## 一、分析前端功能需求

通过分析前端代码，发现以下核心功能需求：

### 1. 房型差价设置 (RoomTypeDiff.jsx)
- 支持多个差价体系管理
- 每个差价体系包含多个房型差价
- 每个房型差价需要：代码、名称、值、起始日期、结束日期、适用星期
- 支持添加、删除、修改差价体系和差价数据
- 记录操作日志

### 2. 订单管理 (ReservationList.jsx)
- 订单列表展示（订单号、状态、渠道、预订时间、住宿日期、总价等）
- 订单详情查看（基本信息、价格明细、操作日志）
- 订单筛选（订单号、状态、渠道、预订时间、入住日期、离店日期）
- 订单导出功能

### 3. 房控日历 (Inventory.jsx)
- 按房型和日期展示库存数据
- 展示可售数量和已订数量
- 单个日期库存更新
- 批量更新库存
- 导入导出库存数据
- 不同渠道的库存管理

## 四、API端点设计

### 1. 房型差价API
- GET /api/room-type-diffs：获取房型差价列表
- POST /api/room-type-diffs：创建房型差价
- PUT /api/room-type-diffs/{id}：更新房型差价
- DELETE /api/room-type-diffs/{id}：删除房型差价
- GET /api/room-type-diffs/system/{systemId}：获取指定差价体系的所有差价

### 2. 订单API
- GET /api/reservation/filter：筛选订单
- GET /api/reservation/export：导出订单
- GET /api/reservation/{id}/details：获取订单详情

### 3. 库存API
- PUT /api/inventory/batch-update：批量更新库存
- GET /api/inventory/channel/{channelId}：获取指定渠道的库存
- POST /api/inventory/import：导入库存数据
- GET /api/inventory/export：导出库存数据

### 4. 渠道API
- GET /api/channel-codes/active：获取活跃的渠道列表
- PUT /api/channel-codes/{id}/status：更新渠道状态
