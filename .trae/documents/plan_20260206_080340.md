# 集团管理-酒店管理功能前端自动化测试方案

## 测试目标
使用前端自动化测试工具，在前端页面中模拟人工填写表单的过程，对集团管理-酒店管理功能进行完整的测试，包含增删改查操作。

## 测试工具
- **Puppeteer**：Google开发的Node.js库，用于控制Chrome浏览器进行自动化测试
- **Jest**：JavaScript测试框架，用于编写和运行测试用例

## 测试步骤

### 1. 环境准备
- 安装测试依赖：Puppeteer和Jest
- 确保前端和后端服务正常运行

### 2. 登录系统测试
- 打开登录页面
- 输入用户名和密码
- 点击登录按钮
- 验证登录成功并进入系统首页

### 3. 导航至酒店管理页面
- 点击左侧菜单"集团管理"
- 点击"酒店管理"子菜单
- 验证进入酒店管理页面

### 4. 新增酒店测试（5个酒店）
对于每个酒店，执行以下步骤：
1. 点击"新增酒店"按钮
2. **模拟人工填写表单**：
   - 酒店ID：HOTEL006 - HOTEL010
   - 酒店名称：上海虹桥酒店、北京国贸酒店、广州白云酒店、杭州西溪酒店、深圳福田酒店
   - 英文名称：Shanghai Hongqiao Hotel、Beijing World Trade Hotel、Guangzhou Baiyun Hotel、Hangzhou Xixi Hotel、Shenzhen Futian Hotel
   - 星级：五星级/四星级
   - 城市：上海、北京、广州、杭州、深圳
   - 其他必填信息
3. 点击"保存"按钮
4. 验证酒店是否成功添加到列表中

### 5. 表单验证测试
1. 点击"新增酒店"按钮
2. **不填写任何信息**，直接点击"保存"
3. 验证是否显示必填项错误提醒
4. **填写无效格式的酒店ID**（如包含中文）
5. 验证是否显示格式错误提醒
6. **填写重复的酒店ID**
7. 验证是否显示重复错误提醒

### 6. 极值校验测试
1. 点击"新增酒店"按钮
2. **填写超长字符**的酒店名称（超过50个字符）
3. 验证是否显示长度错误提醒
4. **填写无效的电话号码**格式
5. 验证是否显示格式错误提醒

### 7. 编辑酒店测试
1. 选择一个已添加的酒店
2. 点击"编辑"按钮
3. **修改酒店信息**（如酒店名称、星级等）
4. 点击"保存"按钮
5. 验证修改后的信息是否正确显示

### 8. 删除酒店测试（3个酒店）
对于每个要删除的酒店，执行以下步骤：
1. 选择酒店
2. 点击"删除"按钮
3. 在确认对话框中点击"确认"
4. 验证酒店是否从列表中移除

### 9. 最终验证
- 确认最终酒店列表中剩余2个新增的酒店
- 验证所有CRUD操作正常
- 验证表单验证和错误提醒功能正常
