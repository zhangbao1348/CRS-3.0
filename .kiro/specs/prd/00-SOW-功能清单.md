# CRS 中央预订系统 — 功能清单（SOW）

---

## 一、首页

### 1. 首页仪表盘

系统首页，展示酒店运营关键业务指标和数据概览。

---

## 二、订单

### 1. 订单管理

管理酒店所有预订订单，包括订单创建、修改、查询和取消等操作。
1. 支持呼叫中心直接预订订单
2. 支持各个渠道的订单直连和展示
3. 订单支持与 PMS 的直连
4. 订单支持查看酒店信息、入住信息、会员信息、备注信息、优惠信息等信息
5. 支持异常订单的处理

---

## 三、库存管理

### 1. 房控日历

以日历矩阵形式管理各房型的库存、房价和开关房状态。
1. 支持按渠道/房价/开关房三种视图切换
2. 包含 PMS 房控日历，展示从 PMS 系统同步的库存数据
3. 支持酒店级和房型级超预订管理
4. 支持房价级房量管理，控制每个价格计划可售的房间数量
5. 支持渠道级房量管理，控制每个渠道可售的房间数量
6. 支持市场码级房量管理
7. 支持渠道+房型级房量管理，精细控制每个渠道下每个房型的可售数量
8. 支持房价大类级房量控制

### 2. 房态管理

多层级房态控制，管理各维度的开房/关房状态。
1. 支持酒店级房态管理，按日期设置酒店整体的开房/关房
2. 支持房型级房态管理
3. 支持房价级房态管理
4. 支持渠道级房态管理
5. 支持渠道+房型级房态管理
6. 支持市场码级房态管理
7. 支持房价大类级房态控制

### 3. 预订控制

以月度日历形式管理各日期的预订规则。
1. 支持设置取消规则（免费取消/限时取消/不可取消）
2. 支持设置提前预订天数
3. 支持设置最少/最多入住天数
4. 支持酒店级/房价码级/渠道级/房价大类级/市场码级五个维度的预订控制

---

## 四、房型管理

### 1. 房型管理

酒店端房型维护，管理酒店的所有房型信息。
1. 支持新增/编辑房型，包含代码、中英文名称、数量、面积、楼层、窗型、床型、图片等字段
2. 展示集团下发的房型和酒店自建的房型
3. 默认只显示有效（active）状态的房型，已回收的房型不显示
4. 集团下发的房型根据权限控制可编辑范围
5. 支持按代码和名称搜索筛选

---

## 五、价格计划管理

### 1. 价格计划

酒店端价格计划列表，管理酒店的所有价格计划。
1. 展示集团下发的价格计划和酒店自建的价格计划
2. 支持按名称/代码/类型/状态筛选
3. 列表显示房价大类、市场码、来源码、包价、退改政策、担保政策、促销优惠等信息，均为"名称（代码）"格式
4. 支持新增/编辑价格计划，表单结构与集团房价码维护一致
5. 集团下发的价格计划根据 5 个权限开关控制可编辑区域，未开放的字段显示只读提示
6. 支持基础价格计划和多级衍生码（一级/二级）

### 2. 基础价格设置

以日历矩阵形式设置各房型在各价格计划下的每日含税价格。
1. 支持按价格码和日期范围查询价格数据
2. 房型为行、日期为列，每个单元格可直接编辑含税价格
3. 单元格失焦时自动保存到酒店价格表
4. 支持批量设价，可按日期范围、周控（周一至周日）、房型批量设置统一价格
5. 周末日期列标红显示

### 3. 包价设置

酒店端包价管理。
1. 查看和管理本酒店可用的包价列表
2. 包价数据来源于集团包价设置

### 4. 价格查询

以月度日历矩阵只读查看各房型在各价格计划下的价格。
1. 支持按价格计划和月份筛选，价格计划下拉显示格式为"名称（代码）"
2. 每个房型一行，显示该房型在选中价格计划下的每日含税价格
3. 周末日期标红，周末单元格浅黄色背景
4. 已删除的价格显示"-"，无价格为空
5. 房型列左侧固定，日期列可横向滚动

---

## 六、渠道管理

### 1. 渠道列表

渠道的查看和管理。
1. 展示系统中所有渠道信息
2. 支持渠道的基本信息维护

### 2. 渠道映射

渠道与酒店的映射关系管理。
1. 管理渠道与酒店之间的对应关系
2. 支持映射的新增/编辑/删除

---

## 七、数据及报表

### 1. 订单报表

订单维度的数据报表。
1. 支持按时间范围、酒店、渠道等维度查询订单数据
2. 支持报表的图表展示

### 2. 出租率报表

酒店出租率统计报表。
1. 支持按时间范围查看酒店出租率趋势
2. 支持按房型维度分析出租率

### 3. 数据导出

业务数据的导出功能。
1. 支持将报表数据导出为 Excel 等格式

---

## 八、集团管理

### 1. 酒店管理

集团旗下酒店的统一管理。
1. 支持酒店的新增/编辑/删除（软删除），包含基本信息、酒店设施、酒店图片、酒店管控四个 Tab
2. 酒店管控支持房型分配（2 个开关：是否分配+允许修改）和房价码分配（6 个开关：是否分配+5 个权限开关）
3. 支持按房价大类筛选房价码分配列表
4. 房型/房价码分配与集团房型管理、集团房价码管理的分配 Tab 操作同一份数据
5. 支持房价码/房型下发到酒店、回收（软删除）、再次下发（差异对比）、同步更新

### 2. 集团房型管理

集团标准房型模板的统一管理。
1. 支持新增/编辑/删除/启停用集团房型
2. 包含基础信息（代码/名称/大类/最大入住人数/排序/状态/描述）和房型分配两个 Tab
3. 房型分配支持将房型下发到指定酒店，回收后酒店端不再显示
4. 停用房型时提示已被房价码引用的数量

### 3. 集团房价码管理

集团房价码的统一管理，是集团管理的核心功能。
1. 支持新增/编辑/删除/启停用集团房价码
2. 房价码维护包含七个区域：基础信息、包价/早餐、适用房型、价格信息（条件显示）、预订限制、担保及取消规则、促销优惠
3. 支持多级衍生码体系（基础房价码/一级衍生码/二级衍生码），父级按层级严格过滤
4. 衍生码保存时父级房价码和折扣为必填项
5. 房价码分配支持城市筛选（显示酒店数量），6 个开关控制分配和权限
6. 渠道发布支持将房价码发布到指定渠道的指定酒店
7. 删除时检查子衍生码和酒店分配，停用时级联停用子衍生码和已下发酒店的价格计划
8. 保存时检查与已下发酒店的一致性，提示同步更新
9. 衍生码下发时检查父级/祖父级房价码是否已下发到目标酒店
10. 所有下拉选项显示格式为"名称（代码）"，同步弹窗中字段名显示中文

### 4. 市场码管理

市场码的树形结构管理。
1. 最多支持三级树形结构
2. 支持新增/编辑/删除节点
3. 编码唯一性校验（同一租户下不重复），编辑时代码不可修改
4. 被房价码引用时不可删除

### 5. 房价大类管理

房价大类的一级结构管理，用于对房价码进行分类。
1. 支持新增/编辑/删除
2. 编码唯一性校验，编辑时代码不可修改
3. 被房价码引用时不可删除

### 6. 房型大类管理

房型大类的一级结构管理，用于对房型进行分类。
1. 支持新增/编辑/删除
2. 编码唯一性校验，编辑时代码不可修改
3. 被集团房型引用时不可删除

### 7. 渠道码管理

渠道码的树形结构管理。
1. 最多支持三级树形结构
2. 支持新增/编辑/删除节点
3. 编码唯一性校验，编辑时代码不可修改
4. 被渠道发布引用时不可删除

### 8. 来源码管理

来源码的树形结构管理。
1. 最多支持三级树形结构
2. 支持新增/编辑/删除节点
3. 编码唯一性校验，编辑时代码不可修改
4. 被房价码引用时不可删除

### 9. 税和服务费设置

税费项的管理。
1. 支持新增/编辑税费项
2. 包含基础信息（编码/全称/承担主体/计税基数类型）、税率信息、计税规则、合规与备注四个区域
3. 编辑时编码不可修改
4. 所有下拉选项从后端枚举获取

### 10. 包价设置

集团包价的管理。
1. 支持新增/编辑包价
2. 包含代码/名称/类型/发放频率/计数方式/份数/描述
3. 计数方式切换时动态显示对应的份数标签
4. 被房价码引用时不可删除

### 11. 集团担保政策管理

担保政策的管理。
1. 支持新增/编辑担保政策
2. 支持无担保/信用卡/预付/公司/第三方/特殊六种类型
3. 选择信用卡类型时条件显示担保子类型（一律担保/超时担保）和担保金额（首晚/全额）
4. 选择超时担保时再显示最晚到店时间
5. 被房价码引用时不可删除

### 12. 集团取消政策管理

取消政策的管理。
1. 支持新增/编辑取消政策
2. 支持免费取消/限时扣费/不可取消三种类型
3. 选择限时扣费时条件显示行内表单：入住前 X 天，HH:mm 前免费取消，之后扣首晚/全额房费
4. 被房价码引用时不可删除

### 13. 集团设施管理

标准设施的管理。
1. 以列表+弹窗形式管理
2. 弹窗表单包含设施分类/名称/代码/描述/状态

### 14. 档案管理

公司和旅行社档案的管理。
1. 支持新增/编辑档案
2. 基本信息包含档案 ID/名称/类型/等级/联系人/地址
3. 支持为档案分配房价码（按酒店+房价码关联）
4. 状态支持点击切换（需二次确认）

---

## 九、系统设置

### 1. 用户管理

系统用户的管理。
1. 支持新增/编辑/删除/启停用用户
2. 支持重置密码（新密码+确认密码，最少 6 位）
3. 支持按用户名/姓名/状态/归属筛选
4. 支持多角色分配
5. 用户可归属于平台或具体租户

### 2. 角色管理

系统角色的管理。
1. 支持新增/编辑/删除角色
2. 支持菜单权限树分配，以树形结构展示所有系统菜单

### 3. 集团设置

集团级全局参数配置。
1. 集团管控模式（强管控/弱管控）
2. 钟点房（支持/不支持）
3. OTA 促销模式（集团报名/集团设置规则酒店报名/酒店自行管理）
4. 预测价格显示配置（显示携程预测价格/显示美团预测价格）

### 4. 自定义渠道设置

自定义渠道的管理。
1. 支持新增/编辑/删除自定义渠道
2. 渠道代码从集团渠道码管理的叶子节点选择
3. 支持两种对接类型：通过 SWITH 通道对接（德比/畅联）和通过标准 API 对接（实时预订/推送落地/TMC）
4. API 类型下展示对应的接口列表
5. 自动生成 API 秘钥

---

## 全局规则

1. 所有代码字段只允许输入英文字母、数字和下划线（正则：`^[A-Za-z0-9_]+$`）
2. 所有下拉选项显示格式统一为"名称（代码）"
3. 所有数据按租户隔离，不同租户只能看到自己的数据
4. 编辑时代码字段不可修改
5. 删除时检查关联引用，被引用的数据不可删除
6. 酒店删除为软删除，不影响已下发的数据
7. 房价码/房型回收为软删除（设为 inactive），不物理删除数据
