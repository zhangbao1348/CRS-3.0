# 系统设置

系统设置是 CRS 系统的基础管理模块，负责用户账号、角色权限和集团参数的配置管理。

系统设置包含以下菜单：用户管理、角色管理、集团设置。

**全局代码字段规则：** 本模块中所有"代码"类字段（角色代码、渠道代码等）统一只允许输入英文字母、数字和下划线（_），正则表达式：`^[A-Za-z0-9_]+$`。

---

## 1. 用户管理

### 1.1 用户列表 ✅ 已实现

展示系统中所有用户。页面顶部为查询区域，支持按以下条件筛选：

- 用户名（模糊匹配）
- 姓名（模糊匹配）
- 状态（下拉选择，启用/禁用）
- 归属（下拉选择，平台或具体租户）

列表展示以下信息：

| 列 | 说明 |
|----|------|
| 归属 | 平台（蓝色）或租户名称（绿色） |
| 用户名 | 登录账号 |
| 姓名 | 用户真实姓名 |
| 邮箱 | 用户邮箱 |
| 手机号 | 用户手机号 |
| 角色 | 用户拥有的角色，以紫色标签展示，支持多角色 |
| 状态 | 启用（绿色标签）/ 停用（红色标签） |
| 创建时间 | 用户创建时间 |
| 操作 | 编辑、重置密码、启用/禁用、删除 |

列表右上方有"新增用户"按钮。

### 1.2 新增/编辑用户 ✅ 已实现

通过弹窗表单进行新增和编辑，包含以下字段：

- **归属**（选填）：下拉选择，选项为"平台"或具体租户。不选则为平台用户
- **用户名**（必填）：用户输入，编辑时不可修改
- **姓名**（必填）：用户输入
- **邮箱**（必填）：用户输入，需符合邮箱格式校验
- **手机号**（选填）：用户输入
- **密码**（必填，仅新增时显示）：密码输入
- **角色**（必填）：多选复选框，从系统角色列表中选择

### 1.3 重置密码 ✅ 已实现

通过弹窗表单进行密码重置：

- **新密码**（必填）：密码输入，最少 6 位
- **确认密码**（必填）：密码输入，需与新密码一致

### 1.4 其他操作 ✅ 已实现

- **启用/禁用**：点击后直接切换用户状态
- **删除**：需二次确认（Popconfirm）

## 2. 角色管理

### 2.1 角色列表 ✅ 已实现

展示系统中所有角色。列表展示以下信息：

| 列 | 说明 |
|----|------|
| 角色名称 | 角色显示名称 |
| 角色代码 | 唯一标识 |
| 描述 | 角色说明 |
| 状态 | 启用/停用 |
| 创建时间 | 角色创建时间 |
| 操作 | 编辑、分配权限、删除 |

列表右上方有"新增角色"按钮。

### 2.2 新增/编辑角色 ✅ 已实现

通过弹窗表单进行新增和编辑，包含以下字段：

- **角色名称**（必填）：用户输入
- **角色代码**（必填）：用户输入，编辑时不可修改
- **描述**（选填）：用户输入
- **状态**（必填）：下拉选择，启用/停用

### 2.3 权限分配 ✅ 已实现

通过弹窗展示菜单权限树，以树形结构展示所有系统菜单，支持勾选/取消勾选。菜单权限树包括：

- 首页
- 订单
- 库存管理（房控日历、房态管理）
- 房型管理
- 价格计划管理（价格计划、基础价格设置）
- RFP
- 渠道管理（渠道列表、渠道映射）
- 数据及报表（订单报表、入住率报表、数据导出）
- 集团管理（酒店管理、集团房型管理、集团房价码管理、市场码管理、渠道码管理、来源码管理、税和服务费设置、包价设置、集团担保政策管理、集团取消政策管理、集团设施管理、档案管理）
- 系统设置（用户管理、角色管理）

## 3. 集团设置

### 3.1 集团参数配置 ✅ 已实现

集团设置页面用于配置集团级别的全局参数，影响集团下所有酒店的业务行为。

包含以下配置项：

- **集团管控模式**（必填）：单选，固定选项：强管控 / 弱管控
- **钟点房**（必填）：单选，固定选项：支持 / 不支持
- **OTA 促销模式**（必填）：单选，固定选项：集团报名 / 集团设置规则酒店报名 / 酒店自行管理
- **预测价格显示配置**：多选复选框
  - 显示携程预测价格
  - 显示美团预测价格

页面底部有"保存设置"按钮。

注：当前集团设置数据存储在 localStorage 中，未对接后端 API。
