# 房型管理

房型管理是酒店端的房型维护模块，用来管理"这个酒店有哪些房间类型"。所有数据跟着当前选中的酒店走，切换酒店后自动刷新。

酒店的房型有两个来源：
1. **集团下发的房型**：集团管理员在集团房型管理里创建好标准房型，然后通过分配功能下发到酒店。下发后酒店有一份独立的副本，可以在权限范围内修改
2. **酒店自建的房型**：酒店自己创建的房型，不关联集团

---

## 1. 房型列表 ✅ 已实现

打开房型管理页面，首先看到的是房型列表。

页面顶部有搜索区域，可以按代码和名称模糊搜索。右侧有"新增房型"按钮。

列表展示以下信息：

| 列 | 说明 | 举例 |
|----|------|------|
| 代码 | 房型唯一标识，同一酒店内不重复 | GRP3_RT001 |
| 名称 | 房型中文名称 | 豪华大床房 |
| 英文名称 | 房型英文名称 | Deluxe King Room |
| 房型数量 | 这个房型有多少间房 | 30 |
| 面积 | 房间面积 | 45 ㎡ |
| 楼层 | 所在楼层范围 | 3-5 |
| 窗型 | 有窗还是无窗 | 有窗 |
| 状态 | 启用（绿色）/ 停用（红色） | 启用 |
| 操作 | 编辑按钮，点击后跳转到编辑页面 | |

默认只显示启用状态（active）的房型，已被集团回收的房型（inactive）不在列表中显示。

## 2. 新增/编辑房型 ✅ 已实现

点击"新增房型"或列表中的"编辑"按钮后，页面从列表切换到编辑视图（不是弹窗，是当前页面内跳转）。

编辑页面顶部有"返回列表"和"保存"按钮。

编辑页面包含两个 Tab：

### Tab 1：基础信息

两列布局的表单，包含以下字段：

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| 房型代码 | 是 | 文本输入 | 只允许英文字母、数字和下划线，编辑时不可修改 |
| 房型中文名称 | 是 | 文本输入 | |
| 房型英文名称 | 否 | 文本输入 | |
| 房型数量 | 是 | 数字输入 | 这个房型有多少间房，最小值 0 |
| 房型面积 | 否 | 数字输入 | 单位：平方米 |
| 所在楼层 | 否 | 文本输入 | 比如"3-5"、"6-10" |
| 最大入住成人数 | 是 | 数字输入 | |
| 最大入住儿童数 | 否 | 数字输入 | |
| 窗型 | 是 | 下拉选择 | 有窗 / 无窗 |
| 床型 | 是 | 下拉选择 | 1张1.8米大床 / 2张1.2米单人床 / 1张1.5米大床 / 3张1.2米单人床 |

Tab 底部有"返回列表"和"保存基础信息"按钮。点击保存只保存基础信息，不影响设施数据。新增模式下保存成功后自动切换为编辑模式（可以继续编辑设施）。

> **⚠️ 逻辑调整 (2026-05-12)**：为了适配当前“框架先行”的开发模式（前端暂无分类选择器），后端暂时放开了对 `roomTypeCategoryCode` 的强制必填校验。当后续前端补齐房型大类选择功能后，需同步恢复后端强校验逻辑。

### Tab 2：房型设施

按设施分类分组展示，每个分类下有多个设施选项供勾选。样式和酒店管理页面的"酒店设施"Tab 一致——每个分类一个蓝色标题，下面是一排 Checkbox。

设施数据来源于集团设施管理中适用范围为"房型设施"的设施列表。分类包括：清洁服务、网络与通讯、客房布局和家具、洗浴用品、食品饮品、卫浴设施、媒体科技、客房设施、室外景观、便利设施。每个分类下只显示可用的设施。

如果集团还没有添加房型设施，页面会显示提示。

Tab 底部有"返回列表"和"保存设施信息"按钮。点击保存只保存设施数据，不影响基础信息。

**集团下发的房型编辑规则：**
- 集团下发的房型，如果集团开放了"允许酒店修改房型信息"权限，酒店可修改名称、描述等
- 权限未开放时，字段显示为只读
- 房型代码始终不可修改
- 酒店可以补充本地特有信息（房间数量、面积、楼层等）

## 3. 房型与其他模块的关系

- **库存管理**：房型是库存管理的基本维度，房控日历按房型展示库存和房态
- **价格计划**：价格计划的"适用房型"从酒店房型列表中选择
- **基础价格设置**：基础价格按房型 + 日期维度设置，每个房型每天一个价格
- **集团房型管理**：集团房型下发到酒店后，在酒店房型列表中展示
