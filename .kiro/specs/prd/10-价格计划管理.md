# 价格计划管理

价格计划管理是 CRS 系统的酒店端价格管理模块，负责酒店级别的价格计划维护、基础价格设置和价格查询。价格计划管理的数据以当前选中的酒店为上下文，切换酒店后数据自动刷新。

价格计划管理包含以下菜单：价格计划、基础价格设置、包价设置、价格查询。

**全局代码字段规则：** 本模块中所有"代码"类字段统一只允许输入英文字母、数字和下划线。

**基础信息：**

**适用房型：** 按房型大类分组的多选矩阵，数据来源于当前酒店的房型，支持按大类全选

- **折扣**（条件必填）：数字输入，百分比（%）
- **取整方式**（选填）：下拉选择，固定选项：四舍五入/向下取整/向上取整

**预订限制：**
- 需要个人会员等级（多选）
- 需要企业会员等级（多选）
- 提前预订天数限制（范围输入）
- 连住天数限制（范围输入）
- 预订生效时间（日期范围）
- 入住生效时间（日期范围）

**担保及取消规则：**
- **担保规则**：下拉选择，数据来源于集团担保政策管理
- **取消规则**：下拉选择，数据来源于集团取消政策管理

**促销优惠：**
- 可用优惠券（不限制/限制部分/不可用）
- 可用促销（不限制/限制部分/不可用）
- 可用积分兑换（允许后选择固定值或按比例）

**集团下发的价格计划编辑规则：**
- 集团下发的价格计划根据 5 个权限开关决定哪些区域可编辑
- 权限未开放的区域显示为只读状态，鼠标悬停显示提示
- 房价代码和类型始终不可修改

## 2. 基础价格设置

### 2.1 价格日历 ✅ 已实现

基础价格设置以日历矩阵形式展示和编辑各房型在各日期的价格。

页面顶部有以下控件：
- **价格码选择**：下拉选择，仅显示基础房价码（衍生码的价格由系统自动计算，不支持手动设置），显示格式为"名称（代码）"
- **日期范围选择**：日期范围选择器，默认展示从今天起 14 天
- **查询按钮**：点击后加载价格数据
- **批量修改按钮**：打开批量设价弹窗
- **日志按钮**：打开价格操作日志弹窗

价格矩阵以表格形式展示：
- 列：日期（每天一列），表头显示日期和星期，周末日期标红
- 行：每个房型一行，显示该房型在各日期的含税价格
- 价格单元格可直接编辑，失焦时自动保存
- 已删除的价格（status=inactive）显示"-" ✅ 已实现
- 房型列左侧固定，日期列可横向滚动

### 2.2 批量设价 ✅ 已实现

通过弹窗表单进行批量价格设置：

- **日期范围**（必填）：日期范围选择器
- **周控**：多选复选框（周一至周日），支持全选，选择适用的星期几
- **房型与价格**：每个房型独立一行，每行包含：
  - 房型名称（代码）
  - 含税价格输入框（不填则不更新该房型）
  - "删除"复选框（勾选后价格输入框禁用，保存时将删除该房型在所选日期范围内的价格）

不同房型可设置不同价格。确认后批量更新选中日期范围内、选中星期、选中房型的价格。

点击"日志"按钮弹出价格操作日志弹窗，展示当前酒店和价格码下的价格变更记录。

日志列表展示以下信息：

| 列 | 说明 |

| 操作人 | 执行操作的用户名 |
| 操作类型 | 新增（绿色）/ 修改（蓝色）/ 删除（红色）/ 批量修改（蓝色）/ 批量删除（红色） |

## 价格计算逻辑

酒店端的最终售价由以下因素计算：

1. **基础价格**（hotel_prices 表）：按租户 + 酒店 + 房价码 + 房型 + 日期维度存储的含税价格
2. **衍生折扣**：如果是衍生价格计划，在父级价格计划的最终价格基础上按折扣百分比计算

最终价格 = 基础价格 × 衍生折扣（如适用），按取整方式处理小数。

### 衍生价格自动计算（下发时） ✅ 已实现

当衍生房价码从集团下发到酒店时，系统自动根据父级房价码在该酒店已有的价格数据计算衍生价格。

**触发条件：** 集团管理员在房价码分配页面将衍生房价码（一级或二级）分配到酒店

**计算流程：**
1. 系统查找父级房价码在该酒店的所有 active 状态的价格记录
2. 对每条父级价格记录，按衍生码配置的折扣百分比计算衍生价格
3. 按衍生码配置的取整方式处理小数：
   - 四舍五入：保留两位小数（默认）
   - 向下取整：取整数，舍去小数
   - 向上取整：取整数，小数进位
4. 将计算结果写入 hotel_prices 表（已存在则更新，不存在则新增）
5. 如果父级房价码在该酒店无价格数据，则不生成衍生价格，不报错

**示例：**
- 基础房价码 RACK 在酒店 A 的豪华大床房 2026-05-01 价格为 ¥500
- 一级衍生码 WEEKEND 折扣为 90%，取整方式为四舍五入
- 下发 WEEKEND 到酒店 A 时，自动生成：豪华大床房 2026-05-01 价格 = ¥500 × 90% = ¥450.00

### 衍生价格级联更新（价格变更时） ✅ 已实现

当酒店端修改基础价格时，系统自动级联更新所有关联的衍生码价格，支持多级递归。

**触发条件：**
- 单条价格编辑（单元格失焦保存）
- 批量价格设置（批量修改弹窗保存）
- 批量价格删除（批量删除操作）

**级联更新流程：**
1. 用户修改房价码 A 的某个房型在某个日期的价格
2. 系统查找同一酒店下所有以房价码 A 为父级（parentRateCode = A）的 active 状态衍生价格计划
3. 对每个一级衍生码，按其折扣百分比和取整方式计算新价格，更新到 hotel_prices 表
4. 对每个一级衍生码，继续查找以该一级衍生码为父级的二级衍生码
5. 对每个二级衍生码，基于一级衍生码的新价格（而非基础价格），按其折扣百分比和取整方式计算新价格
6. 递归处理直到没有更多下级衍生码

**级联删除流程：**
- 当基础价格被删除（标记为 inactive）时，对应的一级衍生码价格也被级联删除
- 一级衍生码价格被删除时，对应的二级衍生码价格也被级联删除

**示例：**
- 基础房价码 RACK，豪华大床房 2026-05-01 原价 ¥500，修改为 ¥600
- 一级衍生码 WEEKEND（折扣 90%）：¥600 × 90% = ¥540
- 二级衍生码 WEEKEND_VIP（折扣 85%，基于 WEEKEND）：¥540 × 85% = ¥459

**注意事项：**
- 级联计算在价格保存时同步执行，无需手动触发
- 只影响同一酒店、同一房型、同一日期的衍生价格
- 只处理 active 状态的衍生价格计划，已停用的衍生码不参与计算
- 衍生码的折扣和取整方式以衍生码自身的配置为准

### 集团修改衍生码折扣/取整方式时的价格重算 ✅ 已实现

当集团管理员修改了衍生房价码的折扣或取整方式，并同步到酒店时，系统会自动重新计算该衍生码在所有受影响酒店的价格。

**触发条件：** 集团管理员修改衍生房价码的折扣百分比或取整方式，保存后选择同步到酒店

**计算流程：**
1. 系统检测到同步的衍生码折扣或取整方式与酒店端之前的值不同
2. 查找父级房价码在该酒店的所有 active 价格记录
3. 按新的折扣和取整方式重新计算所有衍生价格
4. 更新到 hotel_prices 表

**示例：**
- 集团衍生码 WEEKEND 原折扣 90%，修改为 85%
- 同步到上海锦江饭店后，该酒店 WEEKEND 的所有价格按 85% 重新计算
- 比如父级 RACK 豪华大床房 5月1日 ¥500，原衍生价 ¥450（90%），重算后变为 ¥425（85%）
